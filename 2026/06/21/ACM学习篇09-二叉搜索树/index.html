ACM 学习篇 09：二叉搜索树（BST）

上一篇讲了堆，它能高效维护最值，但无法支持快速查找和有序遍历。二叉搜索树（Binary Search Tree，BST）就是来解决这个问题的：它能在 O(log n) 期望时间内同时支持搜索、插入、删除、有序遍历，是真正全能的动态有序数据结构。

为什么需要 BST

哈希表能在 O(1) 时间查找，但它是"无序"的。如果需要：

  • 查找第 K 小的元素
  • 找一个数的"上界"和"下界"
  • 按顺序遍历数据
  • 查找比 x 大的最小元素

这些有序操作，哈希表无能为力，但 BST 可以做到。

什么是二叉搜索树

BST 是一棵二叉树，每个节点最多有两个孩子，同时满足二叉搜索树性质：

  • 左子树的所有节点值 < 根节点值
  • 右子树的所有节点值 > 根节点值
  • 左右子树本身也是 BST（递归定义）

注意：中序遍历 BST 会得到一个严格升序的序列。这个性质是 BST 几乎所有操作的基础。

        8
       / \
      3   10
     / \    \
    1   6    14

中序遍历：1 → 3 → 6 → 8 → 10 → 14 ✅ 升序

BST 的实现

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

搜索

TreeNode* search(TreeNode* root, int target) {
    if (!root || root->val == target) return root;
    if (target < root->val) return search(root->left, target);
    return search(root->right, target);
}

// 迭代版
TreeNode* searchIter(TreeNode* root, int target) {
    while (root && root->val != target) {
        root = (target < root->val) ? root->left : root->right;
    }
    return root;
}

插入

TreeNode* insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val) root->left = insert(root->left, val);
    else if (val > root->val) root->right = insert(root->right, val);
    // val == root->val 不插入（可重复）
    return root;
}

删除

删除有三种情况：

  • 叶子节点：直接删，返回 null
  • 只有一个孩子：用孩子替代它
  • 有两个孩子：用后继（右子树最小节点）或前驱（左子树最大节点）替换，然后删掉后继/前驱
TreeNode* findMin(TreeNode* node) {
    while (node->left) node = node->left;
    return node;
}

TreeNode* erase(TreeNode* root, int val) {
    if (!root) return nullptr;
    if (val < root->val) {
        root->left = erase(root->left, val);
    } else if (val > root->val) {
        root->right = erase(root->right, val);
    } else {
        if (!root->left) return root->right;
        if (!root->right) return root->left;
        TreeNode* succ = findMin(root->right); // 后继
        root->val = succ->val;
        root->right = erase(root->right, succ->val);
    }
    return root;
}

遍历

// 中序（得到升序）
void inorder(TreeNode* root, vector& res) {
    if (!root) return;
    inorder(root->left, res);
    res.push_back(root->val);
    inorder(root->right, res);
}

// 前序（先访问根，用于序列化/前缀表达式）
void preorder(TreeNode* root, vector& res) {
    if (!root) return;
    res.push_back(root->val);
    preorder(root->left, res);
    preorder(root->right, res);
}

// 后序（后访问根，用于释放内存/后缀表达式）
void postorder(TreeNode* root, vector& res) {
    if (!root) return;
    postorder(root->left, res);
    postorder(root->right, res);
    res.push_back(root->val);
}

BST 的进阶操作

找第 K 小的元素

中序遍历第 K 个元素即第 K 小，时间 O(n)。如果频繁查询，可以给每个节点加一个 size 字段记录子树节点数，这样能做到 O(log n)。

// 中序遍历计数版
int kthSmallest(TreeNode* root, int k) {
    vector in;
    inorder(root, in);
    return in[k - 1];
}

// O(log n) 做法：利用子树大小
struct TreeNode {
    int val, size;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), size(1), left(nullptr), right(nullptr) {}
};

int kthSmallestFast(TreeNode* root, int k) {
    int leftSize = root->left ? root->left->size : 0;
    if (k <= leftSize) return kthSmallestFast(root->left, k);
    if (k == leftSize + 1) return root->val;
    return kthSmallestFast(root->right, k - leftSize - 1);
}

Lower Bound 和 Upper Bound

  • Lower Bound：找 ≥ target 的最小元素（等价于 C++ 的 lower_bound）
  • Upper Bound：找 > target 的最小元素（等价于 C++ 的 upper_bound）
// 找 >= target 的最小节点
TreeNode* lowerBound(TreeNode* root, int target) {
    TreeNode* ans = nullptr;
    while (root) {
        if (root->val >= target) {
            ans = root;
            root = root->left;
        } else {
            root = root->right;
        }
    }
    return ans;
}

// 找 > target 的最小节点
TreeNode* upperBound(TreeNode* root, int target) {
    TreeNode* ans = nullptr;
    while (root) {
        if (root->val > target) {
            ans = root;
            root = root->left;
        } else {
            root = root->right;
        }
    }
    return ans;
}

验证 BST

验证一棵树是否是 BST，不能只比较父子节点，要传递合法上界和下界。

bool isValidBST(TreeNode* root) {
    return validate(root, nullptr, nullptr);
}

bool validate(TreeNode* node, TreeNode* low, TreeNode* high) {
    if (!node) return true;
    if (low && node->val <= low->val) return false;
    if (high && node->val >= high->val) return false;
    return validate(node->left, low, node) && validate(node->right, node, high);
}

BST 最近公共祖先（LCA）

BST 的 LCA 比普通二叉树更简单，因为可以利用大小关系：

TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root) return nullptr;
    if (max(p->val, q->val) < root->val) return lowestCommonAncestor(root->left, p, q);
    if (min(p->val, q->val) > root->val) return lowestCommonAncestor(root->right, p, q);
    return root;
}

BST 迭代器

把 BST 的中序遍历变成流式输出，每次 next() 返回下一个最小的数。

class BSTIterator {
    stack st;
    void pushLeft(TreeNode* node) {
        while (node) { st.push(node); node = node->left; }
    }
public:
    BSTIterator(TreeNode* root) { pushLeft(root); }
    int next() {
        TreeNode* cur = st.top(); st.pop();
        pushLeft(cur->right);
        return cur->val;
    }
    bool hasNext() { return !st.empty(); }
};

典型题

题 1：验证二叉搜索树

LeetCode 98 —— 用上界下界递归验证，时间 O(n)，空间 O(h)。

题 2：二叉搜索树中第 K 小的元素

LeetCode 230 —— 中序遍历第 k 个即为答案，或用 size 字段 O(log n) 求解。

题 3：二叉搜索树的范围和

LeetCode 938 —— 利用 BST 性质剪枝，只遍历可能在 [low, high] 范围内的子树。

int rangeSumBST(TreeNode* root, int low, int high) {
    if (!root) return 0;
    if (root->val < low) return rangeSumBST(root->right, low, high);
    if (root->val > high) return rangeSumBST(root->left, low, high);
    return root->val + rangeSumBST(root->left, low, high) + rangeSumBST(root->right, low, high);
}

题 4：把有序数组转化为 BST

LeetCode 108 —— 取中间元素当根，递归构造左右子树，得到的 BST 是"平衡"的。

TreeNode* sortedArrayToBST(vector& nums) {
    function<TreeNode*(int,int)> build = [&](int l, int r) {
        if (l > r) return (TreeNode*)nullptr;
        int m = (l + r) / 2;
        TreeNode* node = new TreeNode(nums[m]);
        node->left = build(l, m - 1);
        node->right = build(m + 1, r);
        return node;
    };
    return build(0, nums.size() - 1);
}

BST 的时间复杂度

操作 期望（平衡） 最坏（退化成链）
搜索 O(log n) O(n)
插入 O(log n) O(n)
删除 O(log n) O(n)
中序遍历 O(n) O(n)
找最大/最小 O(log n) O(n)

平衡时效率很高，但最坏情况（数据有序插入）会退化成链表。**AVL 树和红黑树**就是用来解决这个问题的——它们通过旋转操作保持树的平衡，把最坏情况也优化到 O(log n)。

BST 的易错点

  • 验证 BST 时不能只比较父子：左孩子小于根、右孩子大于根不够，必须保证整棵左子树都 < 根、整棵右子树都 > 根。
  • 删除操作的后继/前驱要小心：替换后要递归删掉原来的后继节点。
  • 迭代器不要用递归：递归会爆栈，中序遍历用栈模拟。
  • 重复元素的处理：可以选择都放左边或都放右边，但一定要保持一致。
  • BST 和二叉树的遍历不要混淆：BST 的中序是升序，但前序和后序没有这个性质。

什么时候用 BST

看到这些关键词，优先考虑 BST：

  • 需要有序数据（第 K 小、Kth Largest）
  • 需要范围查询（lower_bound、upper_bound、区间和）
  • 需要动态维护有序集合（插入、删除、搜索共存）
  • 需要模拟"流式有序输出"（BST 迭代器）
  • 和哈希表的区别：需要有序时用 BST，不需要有序但要速度时用哈希表

这一篇先记住什么

  • BST 的核心性质：左小右大，中序升序
  • 搜索、插入、删除的递归实现（都要和根比较后递归一边）
  • 删除两个孩子的节点时，用后继（右子树最小）替换
  • 验证 BST 要传上界和下界，不能只比较父子
  • BST 的 LCA 利用大小关系可以 O(log n) 完成
  • BST 最坏退化成 O(n)，平衡树（AVL、红黑树）解决此问题
  • 有序数组转平衡 BST：取中点递归
