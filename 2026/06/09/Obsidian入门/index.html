Obsidian：把笔记变成知识网络

大多数笔记软件帮你做的是"存储"：把内容放进去，需要时找出来。文件夹套文件夹，搜索关键词，基本够用。

但知识不是这样工作的。一个概念的价值，往往来自它和其他概念的关系。Transformer 和 Attention 有关，Attention 和 Self-Attention 有关，Self-Attention 和 BERT 有关……这些关联，放进普通文件夹里就断了，你写笔记的时候建立的连接，下次想用的时候找不回来。

Obsidian 的核心主张是：笔记之间应该有连接，你的知识库应该是一张网，而不是一棵树。

一、Obsidian 是什么

Obsidian 是一个本地优先的 Markdown 笔记软件。

几个关键特征：

本地存储，纯文本。 你所有的笔记都是 .md 文件，存在你电脑上的某个文件夹里。没有云端数据库，没有专有格式，用任何文本编辑器都能打开。这个文件夹叫 Vault（库）。

永远属于你。 公司倒了、产品停服——你的笔记还在。因为它就是一堆 .md 文件。十年后你仍然能读它们，不依赖任何软件。

双向链接。 在笔记里写 [[FlashAttention]]，就自动在当前笔记和 FlashAttention 那篇笔记之间建立了一条链接。并且是双向的——打开 FlashAttention 那篇，能看到"哪些笔记链接了我"。

可扩展。 Obsidian 有丰富的插件生态，社区插件数量超过 1000 个，能实现番茄钟、习惯追踪、数据库查询、手绘白板等各种功能。

免费使用（个人用途），同步功能收费，但你可以用 iCloud / Dropbox / Git 自己同步，完全免费。

二、为什么用 Obsidian

对比其他常见笔记工具

vs Notion：Notion 功能更强（数据库、协作），但所有数据在 Notion 的服务器上，断网无法使用，速度也受网络影响。Obsidian 完全本地，打开即用，数据只在本地。如果你很在意数据隐私和长期可用性，Obsidian 是更好的选择。

vs Apple Notes / 印象笔记：这类工具把笔记锁在专有格式里。Apple Notes 的笔记不是普通文件，想迁移很麻烦。Obsidian 的 .md 文件可以随时用任何工具打开，没有迁移成本。

vs 普通文件夹 + Markdown：直接用文件夹当然也行，但 Obsidian 在上面加了很多东西：双向链接可视化、全局搜索、Graph View、模板……把 Markdown 文件夹变成了真正可用的知识管理系统。

最适合做什么

  • 读书/学习笔记：读完一篇论文或一本书，把核心概念记下来，和已有的笔记建立连接
  • 技术知识沉淀：工作中遇到的问题和解决方案，长期积累的技术笔记
  • 写作草稿：先把想法碎片化记下来，慢慢组织成完整文章
  • 日记/周记：搭配 Calendar 插件，按日期管理日常记录

三、核心概念

Vault（库）

Vault 就是一个普通的文件夹，里面放你所有的 .md 笔记文件。Obsidian 打开 Vault 后，把它当成一个整体管理——搜索、链接、图谱，都在这个 Vault 范围内。

你可以建多个 Vault，比如一个用于工作笔记，一个用于个人知识库，互不干扰。

双向链接（Backlinks）

这是 Obsidian 和普通文件夹最大的区别。

在笔记里用 [[文件名]] 语法创建链接：

今天读了关于 [[FlashAttention]] 的论文。
它解决的核心问题和 [[GPU资源模型]] 里讲的内存带宽瓶颈有关。

这样，FlashAttention 那篇笔记的"被链接"（Backlinks）面板里就会出现这篇笔记——你不需要手动维护这个关系，链接是双向自动的。

这个机制的价值在于：几个月后你打开 FlashAttention 笔记，能看到"还有哪些地方提到了它"，发现你自己都忘了的关联。

Graph View（图谱视图）

把所有笔记和它们之间的链接关系，可视化成一张节点图。每个笔记是一个节点，每条链接是一条边。链接越多的笔记，节点越大。

这张图能让你看到知识库的整体结构：哪些概念是核心枢纽、哪些笔记是孤立的（没有任何链接，说明还没和其他知识建立连接）、哪些领域的笔记自然形成了聚簇。

标签和属性（Tags & Properties）

除了双链，还可以用标签分类：

---
tags: [论文, AI, 推理优化]
date: 2026-06-09
status: 阅读中
---

# FlashAttention 笔记
...

文件开头的 --- 之间是 YAML 格式的属性（Frontmatter），Obsidian 能识别并用于筛选和查询。这是构建结构化知识库的基础。

四、基本使用：快速上手

安装和创建 Vault

从 obsidian.md 下载，支持 macOS / Windows / Linux / iOS / Android。

打开后选择"Create new vault"，指定一个本地文件夹，比如 ~/Documents/MyNotes。这个文件夹就是你的 Vault。

创建和链接笔记

# FlashAttention 阅读笔记

来源：arxiv.org/abs/2205.14135

## 核心洞察
标准 Attention 的瓶颈是 [[内存带宽]]，不是算力。
具体原理见 [[GPU资源模型#HBM]]。

## 三个关键技术
1. **分块 Tiling**：把 Q/K/V 切成小块加载进 SRAM
2. **在线 Softmax**：增量计算，不需要物化 N×N 矩阵
3. **反向重计算**：不存储注意力权重，反向时重新计算

## 相关
- [[FlashAttention-2]]
- [[PagedAttention]]
- [[vLLM]]

[[文件名]] 创建链接，[[文件名#标题]] 链接到具体章节。如果被链接的文件不存在，Obsidian 会显示为红色链接，点击可以快速创建那篇笔记。

常用快捷键

  • Cmd/Ctrl + N：新建笔记
  • Cmd/Ctrl + O：快速打开（搜索笔记名）
  • Cmd/Ctrl + Shift + F：全局搜索（搜索所有笔记内容）
  • [[：触发链接自动补全
  • Cmd/Ctrl + P：命令面板（搜索所有可用命令）
  • Cmd/Ctrl + E：切换编辑/预览模式

文件夹结构

Obsidian 不强制任何文件夹结构，但一个常见的起点：

MyNotes/
├── 00-Inbox/         # 临时放刚记录的想法，等待整理
├── 01-Projects/      # 进行中的项目笔记
├── 02-Areas/         # 长期关注的领域（工作、读书、健康…）
├── 03-Resources/     # 参考资料、阅读笔记
├── 04-Archive/       # 归档的旧笔记
└── Templates/        # 笔记模板

这是 PARA 方法的 Obsidian 版本。但不要一开始就设计太复杂的结构——先用起来，随着笔记增多再慢慢调整。

五、常用插件推荐

在 Settings → Community Plugins 里启用插件市场，搜索安装：

Dataview：用类 SQL 语法查询笔记。比如显示所有 status 为"阅读中"的笔记：

TABLE date, tags
FROM ""
WHERE status = "阅读中"
SORT date DESC

这让你的笔记库变成了一个可查询的数据库。

Templater：比内置模板更强大的模板插件。可以在模板里用 JavaScript 写动态内容，比如自动填入今天日期、当前文件名：

---
date: <% tp.date.now("YYYY-MM-DD") %>
title: <% tp.file.title %>
status: 草稿
---

# <% tp.file.title %>

Calendar：在侧边栏显示日历，点击日期直接跳到或创建那天的日记。适合做每日记录的人。

Excalidraw：在 Obsidian 里画手绘风格的图，可以把图片嵌入笔记。解释复杂系统架构时很好用。

Obsidian Git：自动把 Vault 提交到 Git 仓库，实现版本控制和备份。免费同步方案之一。

Advanced Tables：让 Markdown 表格编辑体验好很多，支持 Tab 键在格子间移动、自动对齐。

六、适合谁，怎么开始

Obsidian 不是所有人的最优解。适合你的条件：

  • 你不介意用 Markdown（或者愿意学一点点 Markdown 语法）
  • 你有长期积累知识的需求，而不只是临时记录待办事项
  • 你在意数据归你所有、不被某个平台锁定
  • 你愿意花一点时间配置工具

如果你只是需要一个简单的待办清单或者临时便签，Obsidian 有点重了。

怎么开始：

  1. 下载安装，新建一个 Vault
  2. 记几篇最近在看的笔记，有意识地在里面用 [[]] 创建链接
  3. 打开 Graph View，看看你的知识网络长什么样
  4. 安装 Dataview 和 Templater 两个插件，解锁更多可能
  5. 不要一开始就花大量时间"设计系统"——先记，系统会自然生长出来

最后一点值得强调：很多人在 Obsidian 上花了很多时间折腾插件和结构，但记的笔记很少。工具是手段，不是目的。先用起来，再慢慢优化。

七、总结

  • Obsidian 是什么：本地优先的 Markdown 笔记软件，所有笔记是纯文本文件，永远归你所有
  • 核心差异：双向链接让知识之间有连接，Graph View 让知识结构可视化
  • 基本语法：[[文件名]] 创建链接，YAML Frontmatter 定义属性，#标签 分类
  • 必装插件：Dataview（查询）、Templater（模板）、Calendar（日记）
  • 开始建议：别花太多时间设计系统，先记笔记，边用边优化
